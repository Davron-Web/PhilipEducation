# Отключённые экраны

Здесь лежат шаблоны, которые сейчас не используются, но нужны, когда
функцию включат обратно. Blade их не найдёт: имя папки начинается с
подчёркивания и на неё не ссылается ни один контроллер.

## verify-email.blade.php

Страница подтверждения почты: ввод шестизначного кода, повторная отправка,
адрес получателя и ссылка «изменить адрес».

Чтобы вернуть подтверждение почты:

1. Перенести файл обратно в `resources/views/auth/`.
2. В `routes/auth.php` вернуть четыре маршрута — см. комментарий на их месте.
3. Модели `App\Models\User` вернуть `implements MustVerifyEmail`.
4. В `routes/web.php` добавить middleware `verified` разделам уроков,
   словаря и тестов (и на `/public/lessons`, иначе ограничение обходится
   сменой префикса в адресе).
5. В `ProfileController::update()` вернуть сброс `email_verified_at` при
   смене адреса и отправку нового кода.

Сервис `EmailVerificationCodeService`, письмо `VerifyEmailWithCode`,
модель `EmailVerificationCode` и её таблица остались на месте и работают —
их трогать не нужно.

Причина отключения: письма с локальной машины уходят в спам Gmail, и
подтверждение запирало живых пользователей. Возвращаем после переезда на
хостинг, где почта будет настроена с SPF и DKIM.
