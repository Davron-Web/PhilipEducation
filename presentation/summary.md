# Philip Education — фактическая выжимка для презентации

Источник всех цифр — прямой запрос к рабочей базе данных проекта
(11 сентября 2026) и файлы `composer.json`/`config/`. Ничего не оценено
приблизительно и не придумано; где данные отсутствуют или неоднозначны,
это указано отдельно.

## Название и назначение

**Philip Education** — платформа для изучения английского языка: уроки,
грамматика, словарь, тесты, подготовка к IELTS и разговорная практика
с AI-ассистентом. Интерфейс на русском, с переключением на английский
и таджикский.

## Технологический стек

- **Backend**: Laravel 13.20 (PHP ^8.3)
- **База данных**: MySQL
- **Frontend**: Blade-шаблоны, Tailwind CSS 3 (собирается локально через Vite,
  не через CDN), Alpine.js
- **AI-интеграция**: Google Gemini API (модель `gemini-3.5-flash-lite`) —
  на ней работает ассистент «Фил» (чат с контекстом по разделу сайта),
  генератор учебного контента в админке и разговорный бот «Дракоша» в
  разделе IELTS Speaking
- **Аутентификация**: Laravel Sanctum
- **Локализация**: 3 языка — русский, английский, таджикский

## Разделы сайта — что умеет каждый

- **Уроки** — 150 уроков по уровням A1–C1, каждый с теорией, таблицей
  примеров (утверждение/отрицание/вопрос), словами и тестом.
- **Грамматика** — 317 тем, сгруппированных по категориям (Adjectives,
  Adverbs, Tenses и др.), с разбором правил.
- **Словарь** — 2 468 слов с транскрипцией, переводом, примером
  и озвучкой; можно добавлять свои слова и отмечать выученные.
- **Выражения** — 38 идиом и устойчивых фраз с переводом и примером.
- **Упражнения** — 452 интерактивных задания (заполнить пропуск,
  сопоставление и др.), привязанные к урокам.
- **Тесты** — 150 тестов по уровням, с ограничением по времени и
  разбором результата.
- **IELTS** — все 4 навыка экзамена (Reading, Listening, Writing,
  Speaking) в формате, близком к настоящему экзамену; для Writing
  предусмотрена проверка ответа ИИ.
- **Устная практика («Дракоша»)** — голосовой диалог с AI-ассистентом
  в образе дракончика: распознавание речи, ответ голосом, разбор ошибок
  после разговора.
- **Достижения и геймификация** — очки опыта (XP), звания, streak
  (дни подряд), 8 достижений с прогрессом.
- **Личный кабинет** — сводка прогресса, продолжение обучения одним
  кликом, статистика, лента активности.
- **Админ-панель** — управление всем перечисленным контентом, students,
  тарифами, платежами; есть встроенная AI-генерация нового урока по теме.

## Статус проекта

### Готово и работает
- Весь образовательный контент (см. таблицу выше) наполнен и опубликован.
- Личный кабинет, геймификация, устная практика с AI, генератор контента
  в админке — реализованы и протестированы (262 автотеста проекта
  проходят).
- Локализация на 3 языка.
- Регистрация и вход пользователей.

### В процессе / сознательно отложено
- **Приём платежей** — в проекте настроен только тестовый «песочочный»
  платёжный шлюз (`PAYMENT_GATEWAY=sandbox` в конфигурации), который
  подтверждает оплату без реального списания денег и намеренно
  заблокирован на боевом сервере кодом проекта. Интеграция с реальным
  платёжным провайдером (для приёма настоящих денег по тарифам выше)
  не подключена.
- **Деплой на постоянный хостинг** — проект пока разворачивается и
  тестируется локально; выход на боевой сервер (домен, TLS,
  production-конфигурация) ещё предстоит.
- Часть пользовательской базы (1 105 из 1 112 аккаунтов) — тестовые
  записи для наполнения демо-версии, не реальные ученики.
