# Отключённые тесты

Тесты функции, которая сейчас выключена, но не удалена. Они лежат вне
наборов `Unit` и `Feature` из `phpunit.xml`, поэтому `php artisan test` их
не запускает, а история изменений сохраняется.

## Подтверждение почты

- `EmailVerificationCodeTest.php` — код из шести цифр: верный подтверждает,
  неверный считает попытки, истёкший отклоняется, после пяти попыток код
  сгорает, повторная отправка не чаще раза в минуту.
- `EmailVerificationTest.php` — доступ к разделам до подтверждения,
  закрытый обходной путь `/public/lessons`, письмо на русском.
- `Auth/EmailVerificationTest.php` — исходные тесты Breeze для ссылки.

Проверки адреса при регистрации — MX-запись домена и список одноразовых
почт — **остались рабочими** и живут в `tests/Feature/RegistrationValidationTest.php`.

Чтобы вернуть: включить подтверждение по инструкции в
`resources/views/auth/_disabled/README.md`, затем перенести эти файлы
обратно в `tests/Feature/`.
